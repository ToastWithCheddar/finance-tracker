# TaskSpec: FT-008 — Budgets Adapter + Service Alignment

- ID: FT-008
- Purpose: Add a budgets adapter (DTO → view model) and align FE budget service calls/params to the backend contract; refactor a single UI usage to the adapter.

- FE files: `frontend/src/services/budgetService.ts`, `frontend/src/pages/Budgets.tsx`, `frontend/src/hooks/useBudgets.ts`.

## Exact Changes
- Create `budget.ts` adapter:
  - Export `toBudgetView(dto: any)` to map snake_case → camelCase (e.g., `amount_cents → amountCents`, names/dates as strings).
  - If list envelopes differ, optionally export `toBudgetList(payload: any)` similar to transactions approach.
- In `budgetService.ts`:
  - Align query params to contract: typical pagination `skip/limit` or `limit/offset` per spec; date filters `start_date/end_date` if present; any totals in cents.
  - For the main list method, map items via `toBudgetView` before returning to callers.
- Update `memory/integration-map.md` Budgets section to reference the adapter path.

## Acceptance Criteria
- Budget list method(s) use contract-aligned params and return items mapped via the adapter.
- One UI usage (Budgets page or hook) continues to work without downstream changes.
- `npm --prefix frontend run type-check` passes; `./scripts/smoke.sh` passes.
